# Project workflow

- Work through the numbered learning path one requested step at a time.
- Implement the step, run the relevant verification, save its evidence, and update the learning checklist before marking it complete.
- After each completed step, create a separate descriptive Git commit and push it to `origin` on `main`. The user has authorized this workflow; no additional confirmation is needed for each step's commit and push.
- Do not combine multiple completed steps into one commit.
- Keep local credentials, `.local/`, and environment secrets out of Git. Stage only files belonging to the completed step and its documentation.
- Preserve existing Git history; do not force-push.

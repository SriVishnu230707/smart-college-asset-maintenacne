# Smart College Asset & Maintenance Management System

Learn PostgreSQL and SQLAlchemy by building a college maintenance system one step at a time.

Step 1 is documented: the [project contract](docs/PROJECT_CONTRACT.md) defines the business rules that later database and API work must enforce. The [Step 1 lab](labs/step-01/notes.md) contains worked examples, acceptance scenarios, and questions to check your understanding.

Start here:

1. Read the [project contract](docs/PROJECT_CONTRACT.md).
2. Work through the [Step 1 proofs](labs/step-01/notes.md).
3. Continue with Step 2 in the [learning path](docs/LEARNING_PATH.md).

The [mastery guide](docs/POSTGRESQL_SQLALCHEMY_MASTERY.md) explains how later SQL, ORM, transaction, and reporting lessons connect to the project.

Current deliverable: requirements and worked acceptance examples. Database setup, models, API routes, and runtime enforcement are later learning steps.
